# Security

Please do not open a public issue for a security problem. Report it privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/mixlayer/cli/security) of this repository. We'll acknowledge it and keep you updated on the fix.

Useful details: the CLI version (`mxl --version`), the command involved, and what data could be exposed (for example, an API key, vault contents or unmasked personal data sent upstream).
